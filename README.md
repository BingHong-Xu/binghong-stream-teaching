## 🚀 如何開啟與瀏覽網站

### 方法一：直接點擊開啟（零相依性，完全免伺服器）
直接在 Windows 檔案總管中，對著 **`index.html`** 或 **`special-sustainability.html`** 連按兩下，即可使用 Chrome、Edge 或預設瀏覽器開啟網站，所有圖片、PDF 審查報告、99 項佐證、93 本相簿膠卷與互動篩選皆能 100% 離線正常運作！

### 方法二：使用內建一鍵啟動伺服器（推薦）
在 Windows 檔案總管中，對著 **`start_preview.bat`** 連按兩下，程式會自動啟動 Node.js 伺服器並開啟 `http://localhost:3000`。
